# ============================================================================
#  DUI Dynamic Topbar HUD  --  脚本化本地化（动态文本分发）
#  ---------------------------------------------------------------------------
#  工作原理（黑冰同款思路）：
#    1. GUI 里的文本框写 text = "[GetDUISlot0Text]"
#    2. 这个 defined_text 用格子绑定的 token 拼出本地化键：
#         [?dui_slot_0.GetTokenKey]_text   ->  例如 dui_m_pp_text
#    3. 该键的内容就是真正的实时数值，例如 "[?political_power|0]"
#       （直接引用游戏内置只读变量，每 tick 自动刷新）
#
#  想加新指标：在 localisation 里补 4 个键即可
#      dui_m_xxx         名称（选择菜单显示）
#      dui_m_xxx_text    数值格式
#      dui_m_xxx_sprite  图标（原版精灵名）
#      dui_m_xxx_tt      悬停说明
# ============================================================================
