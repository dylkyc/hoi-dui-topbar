# 规范与硬性约束（违反就会整块失效）

## 一、文件编码

| 文件类型 | 编码要求 | 违反后果 |
| --- | --- | --- |
| `.gfx`（精灵定义） | **必须无 BOM**（ASCII 更稳） | 图标全不加载：`Unexpected token: spriteTypes, near line: 1` |
| `localisation/*.yml` | **必须 UTF-8 带 BOM**（`EF BB BF`） | 该文本不生效 / 游戏提示应使用 utf-8-bom |
| `.ps1`（自检脚本） | 无 BOM + **注释只用 ASCII** | Windows PowerShell 按 ANSI 解码，脚本语法报错 |
| `common/**/*.txt`、`interface/*.gui` | UTF-8 无 BOM（可含中文注释，但注释里不要出现会在解析上引起歧义的全角符号） | 解析异常 |

## 二、语法禁区

1. **按钮不能写 `size`** —— `buttonType` 写 `size` 会报 `Malformed token: width/height`；尺寸由外层容器决定。
2. **一行一条语句** —— 两条语句挤在同一行会导致后者被当成前者的参数（例如 `clear_array = X	add_to_array = { … }`）。
3. **`}` 后面不能直接跟标识符** —— `}	name = "x"` 这种粘连会让整个 `.gui` 从该行开始解析失败（已在 `validate.ps1` 里加检查）。
4. **元素必须写在它所属的窗口/容器内部** —— 脚本化 GUI 引用的元素若不在 `window_name` 声明的窗口内，会出现
   `references element '<x>' owned by '<y>' (outside its own window)`。
5. **`dirty` 变量要用递增** —— `add_to_variable = { dui_menu_dirty = 1 }`；用 `set_variable` 重复设同值不会触发重绘。
6. **取值放在脚本化本地化里做** —— `set_temp_variable` → 输出 `[?变量|格式]`；直接在 loc 文本里写 `[?num_equipment@大类]` 取不到值。
7. **`@` 类装备变量** —— 只有 `num_equipment@大类` / `num_equipment_in_armies@大类` / `num_equipment_in_armies_k@大类` / `num_target_equipment_in_armies@大类` 这几种实测可用。

## 三、自检脚本（每轮改完必跑，都要 0 问题）

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
& 'D:\Local_Mod\Hearts of Iron IV\dui_topbar_dev\validate.ps1'    # 结构 / 元素引用 / 精灵 / 菜单容量 / 本地化键 / 粘连行
& 'D:\Local_Mod\Hearts of Iron IV\dui_topbar_dev\check_vars.ps1'  # 变量名是否真实存在（含自建 dui_* 白名单）
```

> 注意：`check_vars.ps1` 的白名单只覆盖"我们已确认可用 + 自建"的变量名；新加变量时要同步补充，
> 否则会把正确写法误报为 `unknown game variable`。

## 四、复制到游戏（必须自证，否则会测到旧版本）

```powershell
$src = 'D:\Local_Mod\Hearts of Iron IV\dui_topbar'
$d   = "$env:USERPROFILE\Documents\Paradox Interactive\Hearts of Iron IV\mod\top_barUI"
Remove-Item $d -Recurse -Force
Copy-Item $src $d -Recurse -Force
# 自证：逐文件 MD5 比对（无输出即已同步）
Get-ChildItem $src -Recurse -File | ForEach-Object {
  $rel = $_.FullName.Substring($src.Length+1); $ip = Join-Path $d $rel
  if(!(Test-Path $ip) -or (Get-FileHash $_.FullName -Algorithm MD5).Hash -ne (Get-FileHash $ip -Algorithm MD5).Hash){ "未同步: $rel" }
}
```

另外：`.mod` 指到 `mod/top_barUI`，并确认 `dlc_load.json` 的 `enabled_mods` 含 `"mod/top_barUI.mod"`。

## 五、排查顺序（每次出问题照这个走）

1. 读 `C:\Users\<用户>\Documents\Paradox Interactive\Hearts of Iron IV\logs\error.log`，搜 `dui` / `scripted_gui` / `Unexpected` / `Malformed`；
2. 确认安装副本与工作区一致（MD5），排除"测的是旧版本"；
3. 用截图确认界面现象（错位 / 遮挡 / 截断 / 图标错配，这些日志看不到）；
4. 对照原版同类窗口（后勤、陆军总览）取基准值，且必须**同屏/同时刻**比较；
5. 改完回读文件核对 + 跑自检 + 写 CHANGELOG。
